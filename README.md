# Solar Panel Fault Detection

A CNN-based deep learning application that detects solar panel conditions from uploaded images.

## Live Demo
[Click here to use the application](https://solar-panel-fault-detection-mcqb9nxntwrmhe2jfcqtt2.streamlit.app/)

## Technologies Used
- Python
- TensorFlow / Keras
- Streamlit
- NumPy
- Pillow

## Features
- Upload a solar panel image
- Predict the panel condition across six classes
- Display prediction confidence
- Show suggested maintenance guidance

## Classes
- Bird-drop
- Clean
- Dusty
- Electrical-damage
- Physical-Damage
- Snow-Covered

## How to Run Locally
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `streamlit run app.py`.

## Note
This project is an educational prototype. Predictions and maintenance recommendations should be independently verified before real-world use.
